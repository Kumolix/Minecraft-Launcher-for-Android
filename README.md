# SimpleMC Launcher (этап 1)

Офлайн-лаунчер Minecraft Java для Android: ник `Player`, версия `1.21.3`.
Кнопка «Играть» скачивает файлы игры (клиент, библиотеки, ресурсы) и собирает команду запуска.
Java-рантайма и графики пока нет, это следующие этапы.

## Сборка APK через GitHub
1. Загрузите содержимое проекта в репозиторий (папку `.github` тоже).
2. Откройте вкладку Actions. Сборка запускается сама после загрузки (или «Run workflow»).
3. Когда сборка зелёная, откройте её и скачайте артефакт `mini-launcher-apk`.
4. Распакуйте zip, установите `app-debug.apk` (разрешите установку из неизвестных источников).
